# v167 pre-freeze pilots: looped SmolLM2 retrofit (2026-10-04)

- **Model:** healing run 1 (11-8-11 split, no drop; `docs/retrofit_heal_nodrop_2026-10-02.md`). Private Kaggle dataset
  `retro-smollm2-healed` on both accounts.
- **Driver:** `v167_retrofit_trunc.py`, R = 8, GSM8K recipe as v162–v166.
- **Data:** frozen model and controls only; no truncated treatment cell trained. Outputs in `results_v167_pilot/`.

## Design note (before any run)

A review critique, accepted: beating a "k alone" rule borrowed from Parcae on this model would be hollow. The
retrofit's loop settles within ~4 passes, so near-zero cost at k = 1–2 is expected on any account. The test therefore
becomes:
- **(i) Transfer of the curve's numbers.** Do Parcae's φ = c·errᵖ numbers predict this model's costs, unchanged?
- **(ii) A fair rival.** "k alone" fitted on this model's own undamped cells, scored on damped cells, where loop
  damping raises err at the same k.

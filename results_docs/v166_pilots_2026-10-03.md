# v166 pre-freeze pilots (2026-10-03)

Pilots for the draft `docs/prereg_v166_slam_dunk.md`. They cover the frozen model, a 1-seed LR check and feasibility only.
No treatment (truncated) cell was trained. Outputs are in `results_v166_pilot/{A,B}/`.

## Pilot A: over-relaxation on Parcae-140m (a > 1). Result: NOT USABLE, and the arm is dropped

| a | test loss R 32 / R 64 | ρ | err k = 1 / 2 / 3 / 4 |
|---|---|---|---|
| 1.00 | 2.6123 / 2.6123 | 0.825 | 0.820 / 0.675 / 0.546 / 0.443 |
| 1.15 | 2.6131 / 2.6137 | **0.885** | 0.814 / 0.653 / 0.515 / 0.403 |
| 1.30 | 2.6670 / 2.6899 | **0.944** | 0.830 / 0.657 / 0.536 / 0.432 |

- **ρ goes up, not down.** The draft predicted 1 − a + a·ρ₀ ≈ 0.77 at a = 1.3. That formula only holds for loop modes
  with positive real eigenvalues. Over-relaxation pushes modes with small or negative eigenvalues past −1 in magnitude
  (λ = −0.5 → −0.95 at a = 1.3), so the slowest backward mode gets *slower*. The tiny local check had passed only
  because its toy loop had no such modes.
- **a = 1.3 does not converge to the same function** (Δ test loss 0.055 at R 32, worse at R 64).
- **a = 1.15 keeps the function but barely moves err** (−0.01 to −0.04).
  - Using the v164 curve (φ = 0.376·err^3.45), M_err − M_k at k = 1–4 is −0.022 / −0.015 / −0.02 / −0.015.
  - No cell reaches the |Δ| ≥ 0.04 scoring threshold.
- The over-relaxed control LR check is reported for completeness:
  - full: 3e-4 best (test 1.378), as before;
  - floor: 9e-4 best (1.559), as before;
  - non-finite steps were 5–11.
- Side note: the measured ρ (median adjoint ratio) and err disagree in direction at a = 1.15 (ρ up, err down). This is
  consistent with oscillating modes, which inflate the norm ratio while partly cancelling in the summed gradient. It is
  one more reason the claim is stated in terms of err, not ρ.

**Consequence.** Damping-type knobs on Parcae-140m cannot produce the "opposite direction" cells, where the error rule
predicts *less* cost than "k alone".

## Pilot B: Parcae-370m on a Kaggle T4. Result: FEASIBLE

- **Loading and selftest.**
  - 388M parameters load cleanly.
  - Selftest OK: the damped forward equals v162 exactly; checkpointed vs plain gradient rel. diff 3e-7; fp16 vs fp32
    truncated gradients 0.003–0.006.
- **Frozen model at R 32.**
  - a = 1: ρ 0.868, err (k = 2 / 4 / 8) 0.674 / 0.451 / 0.238.
  - a = 0.5: ρ 0.905, err 0.789 / 0.643 / 0.417.
  - Step-0 test loss 2.306.
- **Controls (1 seed).**
  - Full backprop (k 32), lr 3e-4: test 1.283; 8 non-finite steps; 75 min; peak 11.5 GB.
  - Full backprop, lr 1e-4: diverged (test 8.96; 21 non-finite steps). This is fp16 instability, not an LR optimum.
  - Floor, lr 3e-4 / 9e-4: test 1.442 / 1.436; 25 min each.
- **Gates passed.**
  - Full run fits in memory.
  - Trains ≥ 0.10 nats.
  - Floor gap 0.15 ≥ 0.03.
  - LR 3e-4 / 9e-4 confirmed.

**Discriminating power with the 140m curves (v164 locked versions).**

|---|---|---|---|---|
| a 1, k 2 | 0.674 | 0.096 | 0.102 | 0.006 |
| a 1, k 4 | 0.451 | 0.024 | 0.031 | 0.007 |
| a 1, k 8 | 0.238 | 0.003 | 0.006 | 0.003 |

At a = 1 the 370m model's error curve is nearly identical to the 140m model's, so the undamped cells cannot
discriminate. Only the a = 0.5, k = 2 and 4 cells score, and both are in the same direction as before (M_err > M_k).

**Cost.** Per seed: full 75 min + floor 25 min + truncated runs (~45 min each). So a = 0.5 with {2, 4, 8} on 7 seeds
≈ 27 T4-h (~14 quota-h on T4×2).

## What this means for v166

- The draft's "≥ 2 scored cells in each direction" requirement **cannot be met** with these knobs.
- The opposite direction needs a model whose loop forgets faster at the same k. Candidates are the retrofitted SmolLM2
  models (ρ ≈ 0.35–0.38). That would be a new apparatus (Colab, a different model family), not a v166 tweak.
- Feasible as-is:
  - block A (heavy damping: R 64 a 0.3, k 8/12; R 48 a 0.4, k 4/8/12);
  - block B (370m, a 0.5);
  - all cells in the M_err > M_k direction.
